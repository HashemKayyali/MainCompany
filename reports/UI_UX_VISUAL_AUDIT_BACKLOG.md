# Eventies UI/UX Visual Audit Backlog

Updated: 2026-07-15

## P0 - Arabic visual quality

Arabic is the highest-priority visual issue for the upcoming UI/UX stage.

Acceptance requirements:

- Use a formal, elegant, highly legible Arabic font family.
- Eliminate overlapping lines, clipped glyphs, and compressed text blocks.
- Define deliberate Arabic line-height, font sizes, weights, and spacing.
- Audit RTL/LTR direction, bidi isolation, alignment, icons, forms, tables,
  dialogs, navigation, cards, empty states, loading states, and error states.
- Validate Arabic independently on desktop and mobile.
- Compare every Next Preview screen with the original Eventies website.
- Do not approve CAT-024 until Arabic typography and RTL quality are accepted.

Phase 7 remains out of scope and NOT_STARTED.
